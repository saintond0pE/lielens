## OVERVIEW
LieLens is a high-fidelity intelligence analysis system designed to detect and dissect internet manipulation, psychological exploitation, and fraudulent architectures. Unlike traditional AI assistants, LieLens functions as a **forensic analyst**, using a multi-dimensional reasoning framework to identify hidden tactics in social media, marketing, and crypto-narratives.

## CORE CAPABILITIES
*   **Forensic Dissection Engine**: Analyzes content through 10 distinct lenses (Psychological, Marketing, AI-Probability, etc.).
*   **High-Fidelity Cyber Brutalist UI**: A rigid, industrial-grade instrument panel built for precision analysis.
*   **Multi-Provider Intelligence Loop**: Automatic fail-over between GPT-4o, Claude 3.5, and Grok via Puter.js.
*   **Local Hardened Fallback**: Integrated Python/Gemini engine for offline or high-availability processing.
*   **The Vault**: A secure archive of captured manipulation patterns for forensic study.

## INSTALLATION & DEPLOYMENT

### 1. Prerequisites
*   Python 3.10+
*   Google Gemini API Key (for local fallback engine)

### 2. Environment Setup
Clone the repository and install the forensic dependencies:
```bash
pip install -r requirements.txt
```

Create a `.env` file with your credentials:
```env
GOOGLE_API_KEY=your_gemini_api_key_here
```

### 3. Initialize Engine
Start the local forensic server:
```bash
python server.py
```
Access the terminal at `http://localhost:8000`.
